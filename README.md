# Coach's Clipboard

A phone-friendly app for youth rugby coaches: squad ratings, training attendance and match team selection, matched to a 30-week season plan.

It is a single file, `index.html`, with no build step. Everything is stored in the browser on the device using it. Nothing is sent anywhere.

## Use it

Open the published page on your phone, then add it to your home screen (iPhone: Share, then Add to Home Screen. Android: menu, then Add to Home screen).

## Backups

Squad data lives in the browser's local storage, so clearing site data erases it. The app asks the browser to protect it and shows a reminder when a backup is due. Use Settings, then Save backup file, to keep a copy in Files or iCloud, and Restore from backup file to load it again. Copy squad as CSV gives a spreadsheet-friendly copy that Import can read.
